# participation
Open research and contribution tasks for an evidence-based Wattlize MVP. Synthetic examples, transparent assumptions and reproducible reviews. Private implementation code remains separate.

## Aufgaben

Öffentliche Aufgaben stehen als [Issues](https://github.com/wattlize/participation/issues) bereit. Alle Aufgaben des Digitalpath-Projektlabors sammeln das [Projektboard](https://github.com/users/intiequals1/projects/6) und die [Aufgabenübersicht](https://github.com/intiequals1/digitalpath-site/issues/1).

- [#1 MVP-Basis: vorhandene Spezifikationen und ausführbaren Quellstand abgleichen](https://github.com/wattlize/participation/issues/1)
- [#2 Datenmodell: minimales JSON-Schema und synthetische Testfixtures ableiten](https://github.com/wattlize/participation/issues/2)
- [#3 Regelwerk: Evidenz-Gates und nicht-kompensatorische Vetos mit Tests implementieren](https://github.com/wattlize/participation/issues/3)
- [#4 Ergebnisansicht: Gate-Status, Evidenz und Begründung verständlich darstellen](https://github.com/wattlize/participation/issues/4)

Ergebnisse kommen als Markdown, JSON oder CSV in den Ordner [`docs/`](docs/).
